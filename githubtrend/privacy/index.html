Privacy Policy

ホーム トップ

本アプリケーション「GitHub Trend」（以下「本アプリ」）のご利用にあたって取得する個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリでは、以下の情報を収集する場合があります：

情報の種類 収集目的 収集方法
GitHub ユーザーID（オプション） 認証・パーソナライズ OAuth認証
検索・フィルター履歴 ユーザー体験改善 アプリ使用時
お気に入り保存データ 個人的な情報管理 クラウド同期
利用統計・クラッシュレポート アプリ品質向上 第三者SDK
広告識別子（IDFA）※オプトイン制 パーソナライズ広告 ATT フレームワーク

2. 情報の利用目的

収集した情報は以下の目的のみに使用します：

  • 本アプリのサービス提供・機能改善
  • ユーザー設定・お気に入りの保存
  • GitHub API 経由でのリポジトリ情報取得
  • アプリのバグ修正・品質向上
  • 広告の配信（同意したユーザーのみ）

3. 利用する第三者サービス

本アプリは以下の第三者サービスを利用しており、各社のプライバシーポリシーが適用されます：

GitHub API

トレンドリポジトリ・ユーザー情報の取得に使用します。

GitHub Privacy Policy →

Google AdMob（広告配信）

無料プランのユーザーに広告を表示するために使用します。

Google Privacy Policy →

4. データの安全性

ユーザーデータはクラウドサーバーに暗号化されて保存されます。合理的な技術的・組織的措置を講じてデータを保護しますが、インターネットを経由した通信の完全な安全性を保証することはできません。

5. データの削除

ユーザーはいつでも本アプリ内の設定からアカウントを削除できます。削除を行うと、以下のデータがすべて消去されます：

  • 認証情報
  • お気に入りリポジトリ
  • 検索履歴
  • ユーザー設定

6. Cookie およびトラッキング技術

本アプリはウェブブラウザの Cookie を使用しません。ただし、第三者 SDK がデバイス識別子を使用することがあります。

7. プライバシーポリシーの変更

本ポリシーは必要に応じて改定されることがあります。重要な変更がある場合はアプリ内でお知らせします。

8. お問い合わせ

プライバシーに関するご質問・削除リクエストは、メールでお問い合わせください。
